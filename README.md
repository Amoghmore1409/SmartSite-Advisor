# SmartSite Advisor 🏢🤖

> **Agentic AI-Powered Real Estate Analytics & Multi-Agent Property Verification System**  
> *Targeted for Mumbai, Thane, and Navi Mumbai Real Estate Markets*

---

## 🌟 Overview

**SmartSite Advisor** is a state-of-the-art Web Application and Agentic AI Engine built to solve key challenges in urban real estate: dirty aggregator data, lack of environmental/AQI visibility, and subjective property comparisons.

By deploying a swarm of specialized AI agents, SmartSite Advisor harvests live portal listings from verified platforms (Housing.com, 99acres, MagicBricks), performs multi-modal environmental and financial audits, and orchestrates live consensus debates to help buyers and investors make data-backed decisions.

---

## ✨ Key Features

- 🤖 **Swarm of 6 Specialized AI Agents**:
  1. **Parichay Agent**: Conversational buyer profiling and requirement extraction.
  2. **Valuation & ROI Specialist**: Automated AVM pricing sanity checks and 5-year ROI forecasts.
  3. **GeoSpatial & Environmental Agent**: Live AQI monitoring, green cover indexing, and transit connectivity.
  4. **Negotiation & EMI Specialist**: Down-payment, interest rate, and tenure optimization strategies.
  5. **Constructor Upgrade Agent**: Property seller action plans to maximize listing value.
  6. **Agent Debate Orchestrator**: Multi-agent consensus synthesis engine.
- 📡 **Autonomous Live Scraper & Portal Sync**: Real-time web harvesting and verification badges (`VERIFIED LIVE`).
- 📊 **Plain-English Comparison Dossiers**: Side-by-side multi-property analysis cards.
- 💬 **Interactive AI Neighborhood Expert**: Instant neighborhood queries for individual properties.

---

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite, Framer Motion, Lucide React, Vanilla CSS.
- **Backend**: Node.js, Express.js v5, Mongoose ODM.
- **Database**: MongoDB Atlas (with local MongoDB Memory Server fallback).
- **AI Infrastructure**: Groq LLM Cloud API (LLaMA 3.3 70B), OpenWeatherMap API.
